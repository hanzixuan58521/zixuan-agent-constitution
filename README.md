# Zixuan Agent Constitution

一套经过长期使用和持续调整形成的个人 AI 智能体设定。

它融合了：

- 奥卡姆剃刀
- 第一性原理
- 以终为始
- 无限游戏
- 证据优先
- 有边界的八字命理辅助决策

它的目标不是让 AI 记住更多规则，而是让 AI 在目标冲突、信息不足和长期价值取舍中，更理解我的判断方式。

## 核心价值

这套设定优先保护三项“无限游戏核心资本”：

1. 健康与持续行动能力
2. 信任、信誉与长期关系
3. 成长能力与人生选择权

## 文件

- [AGENTS.md](./AGENTS.md)：完整智能体设定
- [ARTICLE.md](./ARTICLE.md)：设计这套智能体的个人思考

## 使用

可以直接阅读或复制 `AGENTS.md`，根据所使用的智能体平台放入对应的全局或项目规则文件中。

这是一套带有鲜明个人价值观的设定，不主张它是所有人的标准答案。

## 关于命理

命理在本设定中是主动但有边界的参考视角：

- 不替代事实证据
- 不作为唯一决策依据
- 不凌驾于安全、法律、成本和风险之上
- 不把倾向性判断描述为必然结果
